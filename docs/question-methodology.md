# Методика графических заданий IQ.Профиль
Дата: 2026-11-18

## Источник и права
Все 25 задач сгенерированы собственной детерминированной процедурой из кода проекта `database/seeders/QuestionSeeder.php`. Фигуры строятся в `app/Support/GraphicPuzzle.php` через SVG без сторонних графических материалов и без копирования коммерческих наборов Равена, Айзенка, IQMO или IQ Report. Отдельная лицензия на чужой банк задач не требуется, поскольку чужие изображения/формулировки не используются.

## Структура
- Ровно 25 вопросов: 5 семейств × 5 вариантов последовательностей. Семейства: количество точек, число углов многоугольника, поворот стрелки, число полос, позиция маркера в 3×3.
- В каждой задаче 3×3 матрица; нижняя правая ячейка пропущена; предоставлены 6 графических вариантов.
- Индекс состояния определяется формулой `(offset + row * rowStep + column * columnStep) % modulo`.
- `modulo` равен 6 для четырёх семейств и 9 для позиции маркера; пользователь решает закономерность по горизонтали/вертикали.
- Для каждой задачи выборки содержат ровно один правильный вариант: это подтверждает автоматический тест банка вопросов.

## Сложность
Эмпирическая сложность и нормы **не установлены**. Разница комбинаций шагов не означает доказанного возрастания сложности. Банк не является стандартизированной психометрической батареей.

## Оценивание
Правильных ответов: целое от 0 до 25, процент: число правильных / 25 × 100, ошибки: 25 − правильных; время: фактическая продолжительность. Расчёт выполняется сервером по сохранённым ответам после завершения.

**Не допускается вывод нормативного IQ-балла** без источников, репрезентативной выборки и валидного алгоритма. В отчёте это ограничение явно объясняется.
