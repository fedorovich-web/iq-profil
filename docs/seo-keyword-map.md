# SEO и карта поисковых намерений
Дата 2026-11-18. Частотности не исследовались; цифры отсутствуют.

|Интент|Основные формулировки для исследования|Целевая страница|Обоснование|
|---|---|---|---|
|Практический|тест iq онлайн, графический iq тест|/|Самостоятельный набор из 25 задач|
|Практический|логические задачи с фигурами, матричные задачи|/ (секция тестов)|Формат заданий|
|Информационный|как пройти iq тест, сколько вопросов, ограничение времени|/ (FAQ)|Подтверждённое поведение продукта|
|Информационный|как получить результат, сколько стоит открыть результат|/ (FAQ)|Демо-модель оплаты|
|Информационный|показывает ли онлайн тест настоящий iq|/ (FAQ)|Дисклеймер о непрохождении нормировки|

Нет оснований создавать отдельные индексируемые страницы для каждого типа задачи: в MVP это один и тот же набор вопросов, раздельные URL могут привести к каннибализации и тонким страницам.

Сессионные /quiz, /paywall, /checkout, /result получают noindex и недоступны для чужой сессии. Sitemap содержит только Landing. Robots допускает обход, чтобы поисковые системы могли увидеть noindex на приватных URL. Динамические URL формируются по APP_URL.

Следующее исследование при доступе: Яндекс Wordstat, Google Search Console, Яндекс Вебмастер, индексируемость и реальные запросы. Частотности и позиции не выдумываются.
