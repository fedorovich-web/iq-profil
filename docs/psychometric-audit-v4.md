# IQ.Профиль — содержательный аудит банка v4

**20.11.2026.** 25 матриц 3×3, по шесть графических ответов. Статус: техническая и предварительная экспертная проверка, **не** стандартизация IQ.

## Что подтверждено и что не подтверждено

PHP-тест проверяет все шесть вариантов каждого из 25 заданий: ровно один удовлетворяет формально заявленному логическому правилу. SVG проверяются на уникальность, границы геометрии и горизонтальное переполнение на 320, 390, 768, 1440 и 1920 px. Это **не** исключает всех альтернативных человеческих интерпретаций и **не** доказывает измеренную сложность, надежность или валидность теста. Ниже приведены предварительные содержательные оценки.

## Предметный аудит 25 заданий в актуальном порядке

| № | Ключ | Логика | Методический риск / проверка |
|---:|---|---|---|
| 1 | dots-add | По строке справа сумма количеств точек | Очень простое: возможный потолочный эффект |
| 2 | nested-cycle | Цикл из трёх внутренних фигур по строкам и столбцам | Простое повторение; разминка |
| 3 | polygon-steps | Число сторон +1 по обеим осям | Проверить различение 7- и 8-угольников на мобильных |
| 4 | count-subtract | Разность чисел точек | Возможная близость к №9 |
| 5 | direction-mirror | Зеркальное отражение относительно центральной вертикальной стрелки | Ранее неиспользуемый центральный элемент теперь имеет смысл |
| 6 | shape-union | Объединение множеств из трёх фигур | Проверить перенос навыка на №19 |
| 7 | color-count | Цвет по строке, количество по столбцу | Два легко разделимых признака |
| 8 | shape-common | Пересечение двух множеств фигур | Удалена прямая копия соседнего ответа |
| 9 | absolute-distance | Абсолютная разность чисел точек | Родственность с №4 требует эмпирической проверки |
| 10 | orbit-skip | +2 по кругу вправо, +1 вниз | Маркеры должны одинаково читаться на телефоне |
| 11 | compass-step | Поворот +60° вправо, +120° вниз | Двухосевая трансформация |
| 12 | bar-wrap | Число линий +2 вправо, +1 вниз, циклический переход | Ранее слишком простая серия исправлена |
| 13 | bar-difference | Графическая разность множеств полос | Ранее постоянное правое значение исправлено |
| 14 | rotation-composition | Сложение направлений с циклом из шести позиций | Важно однозначное понимание ориентаций |
| 15 | bars-xor | XOR трёх независимых полос | Сходство с другими XOR заданиями |
| 16 | shape-tone-cycle | Цвет по столбцу плюс разный циклический шаг формы по осям | Заменён дублировавший №2 цветовой латинский квадрат |
| 17 | corners-dual | Поворот угла вправо, изменение цвета по вертикали | Два графических признака |
| 18 | mosaic-xor | XOR двух закрашенных квадратов в сетке 2×2 | Нужна проверка альтернативных визуальных эвристик |
| 19 | four-band-union | OR четырёх полос по строкам | Может оказаться проще своего места |
| 20 | grid-traversal | Смещение +3 и +4 по модулю 9 | Проверка маркеров на разных размерах |
| 21 | growing-strides | Число лучей растёт с шагами 1/2/3 по осям | Плотная графика на мобильном |
| 22 | arrow-colors | Поворот + цвет с разными шагами в обоих направлениях | Ранее тривиальная раскладка заменена |
| 23 | xor-two-axes | XOR трёх форм по обеим осям | Устранён пустой вариант |
| 24 | xor-four | XOR четырёх маркеров по обеим осям | Проверить зависимость с №23 |
| 25 | master-four-layer | OR по строкам, XOR по столбцам | Два независимых оператора вместо прежнего двойного OR |

**Порядок сложности редакторский, не эмпирический.** Его нужно пересмотреть после пилотных прохождений. Вопросы №4/9, №6/19 и №23/24 могут оказаться слишком похожими по требуемой операции.

## Проверка пяти неправильных вариантов

Сейчас каждый неправильный ответ уникален по отрисованному состоянию, но это не гарантирует, что все 125 отвлекающих вариантов действительно функциональны. На реальных прохождениях требуется исследовать: долю выбора каждого ответа, частоту ошибок, зависимость ответов от суммы остальных 24 вопросов, задания с потолочным и напольным эффектом, повторные прохождения и вероятность угадывания при шести вариантах.

## Подсчёт и будущая калибровка

Фактический результат — от 0 до 25, по одному баллу за верное решение, без штрафов за скорость и произвольных весов. Процент — 100 × правильные / 25. Пять разделов отчёта рассчитываются по реальным ответам. До получения возрастных норм, репрезентативной выборки и проверки измерительной модели **не выводить IQ, придуманную норму или процентиль**.

Добавлена read-only команда пилотной диагностики:

    php artisan iq:pilot-report --revision=4

Она выводит только агрегированные результаты без персональных данных, частоты A–F, наблюдаемую долю успеха и при не менее 100 корректных завершениях — предварительную корреляцию с суммой остальных 24 заданий. Порог 100 означает только условие показа предварительной статистики, **не** достаточность для психометрической стандартизации. Собственная выборка посетителей сайта может быть смещена; повторные попытки должны анализироваться отдельно.

## Условия публикации

Проверить всю геометрию SVG визуально (а не только через getBBox), затем провести слепой экспертный разбор всех 25 решений, проверить формулировки и качество дистракторов. До деплоя сделать консистентную резервную копию SQLite в Dokploy, проверить миграцию и сохранность предыдущих попыток. Не переписывать опубликованные вопросы и ключи.
