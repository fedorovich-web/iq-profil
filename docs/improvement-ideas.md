# Возможные улучшения после приёмки MVP
2026-11-18

- Версионирование банка задач: устраняет изменение интерпретации старых результатов при добавлении новых вопросов. Трудоёмкость: средняя. Не входит в тестовое задание.
- Персональные подборки задач по типам ошибок после прохождения: повышают практическую ценность отчёта. Трудоёмкость: средняя. Требует независимых норм и валидной таксономии.
- Прозрачный чекбокс автопродления с отдельным подтверждением в настоящем платёжном продукте. В демо нет фактической подписки и рекуррентных списаний.
- Возможность сохранить отчёт в PDF: полезно для пользователя, но потребует отдельной реализации и проверки в текущем MVP не включена.
- Увеличение психометрического разнообразия задач, исследование нормирования: требует лицензий и данных; пока не использовать термин «стандартизированный IQ».
