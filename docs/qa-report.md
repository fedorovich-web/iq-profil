# Контроль качества IQ.Профиль

Этот документ описывает проверяемые сценарии и оставшиеся ограничения. Одноразовые JSON-отчёты и снимки отдельных прогонов не хранятся в Git; при запуске QA они создаются локально.

## Базовые команды

```powershell
php artisan test
vendor\bin\pint --test
npm run build
node scripts/browser-e2e.mjs
```

Браузерный E2E требует Chrome и запущенного приложения. Запускать **только на отдельной тестовой SQLite**, задавая `IQ_TEST_BASE_URL` и путь отчёта `IQ_TEST_REPORT_FILE`. Результаты автоматически создаваемых файлов следует хранить в игнорируемой `.incoming/` или другой временной директории.

## Сценарии

- Главная страница: валидные заголовки, ссылки и формы; адаптивность 320–1440 px.
- Тест: старт, переход между вопросами, изменение ответа, серверное сохранение, завершение, таймер.
- Paywall → demo checkout → отчёт: запрет доступа до подтверждения, идемпотентность подтверждения и повторный просмотр.
- Регистрация, аутентификация, личный кабинет, CSV-экспорт, доступ администратора.
- Запрет просмотра чужих попыток и отчётов (IDOR).
- Демо-подписка: активация, отмена, повторное подтверждение без повторного списания.
- Состояние браузера: отсутствие console/page errors, горизонтального переполнения и скачков FAQ.
- Статические проверки: Pint, Vite, HTML, a11y. Эти проверки не заменяют ручную проверку и приемку.

## Последние локальные результаты (19.11.2026)

- PHPUnit: **45 passed / 2385 assertions**.
- PHP Pint: **51 проверенный файл, ошибок форматирования нет**.
- Vite: production build успешен.
- Основной Playwright E2E: **91/91 проверок**, без ошибок JavaScript в указанном прогоне.
- Проверка адаптивности: **56/56** проверок на восьми контрольных ширинах.
- Composer и npm audit production-зависимостей: известных advisories в проверенном наборе не обнаружено.

Исторические отчёты, подготовленные в отдельные этапы работ, могут содержать более ранние числа тестов. При изменении приложения эти числа нельзя считать актуальными.

## Открытые пункты

- Полный внешний smoke-тест опубликованного HTTPS-домена и сохранение SQLite после реального redeploy.
- Firefox и Safari, независимая проверка доступности с ассистивными технологиями.
- Core Web Vitals на реальном домене.
- Независимая психометрическая экспертиза не проводилась. Результаты не являются нормативным IQ.
- Юридическое оформление коммерческого использования и реальный платёжный провайдер не входят в демоверсию.

Перед публичным релизом каждый пункт должен быть подтверждён фактическим запуском, а не только наличием тестового сценария.
