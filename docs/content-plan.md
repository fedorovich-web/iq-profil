# Контент-план MVP
Дата 2026-11-18

В MVP утверждённая структура Landing: Hero → преимущества → доступные тесты → как это работает → FAQ → CTA → Footer.

## Доказательная стратегия
Структура CTA и концепция Paywall опираются на сравнительный просмотр русскоязычных публичных страниц IQMO, testnaiq.ru, IQMeter, myIQ и WeTest (см. competitor-copy-evidence.md). Точные утверждения о функциональности IQ.Профиль проверяются только по реализации.

Hero не обещает официальную психометрию. FAQ объясняет число вопросов, отсутствие регистрации, ограничений времени, характер демо-платежа и отсутствие валидного IQ-балла. На Paywall перечислены только реальные данные отчёта.

Ограничение: часть исходных визуальных ассетов не перенесена на Windows-устройство из чата; текущие декоративные CSS-элементы не подменяют окончательную интеграцию утверждённых AVIF.
